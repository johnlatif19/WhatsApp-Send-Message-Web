# نظام إدارة الإشعارات - لوحة التحكم الإدارية 🚀

نظام متكامل لإدارة وإرسال الإشعارات للمستخدمين عبر Firebase Cloud Messaging (FCM).

## 📋 نظرة عامة

هذا المشروع يوفر لوحة تحكم إدارية لإدارة المستخدمين وإنشاء وإرسال الإشعارات المجدولة أو الفورية.

### الميزات الرئيسية

- ✅ **مصادقة آمنة** باستخدام JWT
- ✅ **لوحة تحكم احترافية** مع إحصائيات فورية
- ✅ **إدارة المستخدمين** وعرض الأجهزة النشطة
- ✅ **إنشاء إشعارات** يدوية أو مجدولة
- ✅ **إرسال فوري** أو جدولة تلقائية
- ✅ **سجلات الإرسال** لمتابعة الحالة
- ✅ **تصميم متجاوب** يعمل على جميع الأجهزة
- ✅ **حماية API** مع تحديد معدل الطلبات

## 🛠️ التقنيات المستخدمة

| التقنية | الغرض |
|---------|-------|
| **Node.js + Express** | خادم API |
| **Firebase Admin SDK** | إدارة الإشعارات |
| **Firebase Cloud Messaging** | إرسال الإشعارات |
| **Firebase Firestore** | قاعدة البيانات |
| **JWT** | المصادقة |
| **dotenv** | إدارة المتغيرات البيئية |
| **Vercel** | استضافة السيرفر |
